# 1. Architecture
## 機能構成
必要な機能 | 呼び出しモジュール　　　　
クロック源(DFLL48を分周比3で使用する) 任意の間隔でトリガを出力する|GCLKモジュール
GCLKをもとに、GCLKからトリガが来る毎にカウントアップし、カウントがたまったら0に戻る|TCモジュール
TCモジュールのカウンタが0に戻ったらイベントを発行する|EVESYSモジュール
EVESYSが発行されたらメモリに指定されたメモリにアクセスしてメモリの値を読む|DMAモジュール
読み込んだメモリの内容を指定されたメモリに書き込む|DMAモジュール
読み込み先のメモリの位置を指定する値が書き込まれているメモリを決める|DMAモジュール
書き込み先のメモリの位置を指定する値が書き込まれているメモリを決める|DMAモジュール
